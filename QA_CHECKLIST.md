# Чек-лист передачи тестировщикам

Для каждого пункта записать commit, браузер, результат и ссылку на баг. Непроверенное не считать PASS.

- [ ] npm ci, npm test, npm run build завершаются успешно.
- [ ] / и /rpg.html загружаются без ошибок; повтор после сетевого сбоя.
- [ ] MAP01 пройден от нового старта до финала обычным управлением.
- [ ] Границы, препятствия, переходы, NPC, недоступные зоны.
- [ ] Оружие, боеприпасы, урон через стены, смерть, повторное появление.
- [ ] Предметы и награды не дублируются от повторных действий.
- [ ] Верные/неверные ответы, повторные клики, завершение всех заданий.
- [ ] Кат-сцена полностью, пропуск в начале/середине/конце, повторный запуск.
- [ ] Пауза, карта, инвентарь, диалоги: управление восстанавливается.
- [ ] Сохранение/перезагрузка; повреждённые, старые, слишком большие данные; запрет storage.
- [ ] Desktop/tablet/phone: текст, HUD, клавиатура и touch.
- [ ] В SQL: anon/player/teacher/admin; чужие run/session; повтор UUID и новый UUID; закрытая сессия.
- [ ] В тестовом Supabase: OAuth, HTTP-коды, RLS, realtime, разрыв сети и reconnect.
- [ ] Если реализован coop: 4-й участник отклонён сервером, чужой персонаж недоступен, одновременные действия и reconnect.
- [ ] Длительная сессия и повторные переходы: FPS, память, число объектов.
- [ ] Архив исходников и dist не содержат секретов.
- [ ] Нет открытых CRITICAL/HIGH; ограничения описаны и приняты преподавателем.

Кооператив нельзя отмечать PASS на основании тестов классного рейтинга. Демо админпанели не является проверкой реальной авторизации.
