# Tarikh: іске қосу және көрсету

Жоба қалтасында Node.js 22 немесе кейінгі нұсқасымен:

    npm ci
    npm run dev

Терминалдағы жергілікті сілтемені ашыңыз. «Саяхатты бастау» → «Жаңа саяхат» → «Бастайық». WASD — жүру, тінтуір — бұрылу, E — әрекет. Бірінші стелада «Неолит» жауабын таңдаңыз: қақпа жабылады. Алтын белгіден фрагментті тауып, E басыңыз. «Палеолит» деп түзетсеңіз, 60 ұпай беріледі. Ашылған қақпадан өтіп, соңғы белгіде E басыңыз.

Тексеру: `npm test` — PostgreSQL ережелері; `node scripts/check-engine.mjs` — WASM мен он картадағы қозғалыс.

## Топтық ойын және Google арқылы кіру

1. Supabase жобасының SQL Editor бөлімінде supabase/migrations ішіндегі 001, 002, 003 файлдарын осы ретпен орындаңыз.
2. Google Cloud-та Web application OAuth клиентін жасаңыз. Authorized redirect URI ретінде Supabase Google провайдері көрсеткен callback URL мекенжайын енгізіңіз.
3. Supabase Authentication → Providers → Google бөлімінде Client ID және Client secret сақтаңыз. URL Configuration ішінде сайттың HTTPS мекенжайын және әзірлеу кезінде қолданылатын жергілікті redirect URL мекенжайын рұқсат етілген тізімге қосыңыз.
4. .env.example файлын .env.local атауымен көшіріңіз. VITE_SUPABASE_URL және VITE_SUPABASE_PUBLISHABLE_KEY мәндерін толтырыңыз. Серверді қайта іске қосыңыз. Құпия кілттерді клиентке немесе чатқа енгізбеңіз.

## Жариялау

Python 3 және Node.js орнатылған ортада npm run build орындаңыз. dist қалтасының мазмұнын HTTPS статикалық хосттың түбіріне орналастырыңыз. .wasm үшін application/wasm, .js үшін text/javascript MIME түрін қолданыңыз. licenses және tarikh-source.zip файлдарын бірге жариялаңыз. Орта айнымалылары жинақтау кезінде оқылады.

## Ресурстар

Freedoom материалдары мен авторлар тізімі public/licenses ішінде. Спрайттарды assets/manifest.json арқылы ауыстырып, python scripts/prepare-assets.py орындаңыз. Бұл Doom рендерері 3D модельдерді тікелей көрсетпейді: жауынгерлерді бірнеше бағыттан кадрларға, қаруды бірінші жақ көрінісіндегі кадрларға рендерлеу керек.
